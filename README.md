# Lampa Alarm

Плагин-будильник для Lampa на Android TV. **Тестовый проект**.

**Единственная ссылка для установки и обновлений:**

`https://semichang.github.io/Lampa-Alarm/alarm.js`

## Версия 0.3.0

- Раздел «Будильник» через штатный `Lampa.SettingsApi`.
- **Кнопка «В будильник» в карточке сериала**. Используется событие `full → complite` и интерфейсные события `hover:enter`.
- Сохранение в `Lampa.Storage` только метаданных карточки (название, ID, источник TMDB/CUB); не URL потока и не доступов к источникам.
- В настройках можно увидеть выбранный сериал, посмотреть его идентификатор и сбросить выбор. Фильмы кнопкой не помечаются.
- Время (по умолчанию 07:00), включение/отключение, дни недели.
- Настройки будущего воспроизведения: онлайн/TorrServer, продолжение или следующая серия.
- Настройки будущего плавного повышения громкости и ограничения её максимума.
- «Проверить уведомление» и «Показать текущие настройки».
- Защита от двойной инициализации скрипта.
- **Эксперимент:** «Только после пробуждения» — запуск лишь после наблюдения длительной паузы в работе Lampa. Минимум простоя: 15/30/60 мин, окно запуска: 1/3/5 мин.
- «Проверить обнаружение сна» — показывает, видела ли текущая сессия длительную паузу.

### Текущие ограничения

- **Видео не запускается, громкость не регулируется:** эти функции пока только на этапе подготовки настроек.
- Встроенный таймер включения телевизора настраивается в Android TV отдельно. JS-плагин не может гарантированно вывести TV из сна.
- Чистый JavaScript Lampa **не способен достоверно различать** авто-включение TV по расписанию, ручное включение или возвращение в приложение после долгого простоя.
- Экспериментальный режим основан на `visibilitychange` и разрывах между вызовами таймера. Он может ошибочно распознать возвращение из другого приложения как пробуждение TV, а если Android перезапустит WebView — **не увидит пробуждение вовсе**.
- Поэтому защитный режим **выключен по умолчанию** и не влияет на обычные проверки расписания до включения в настройках.
- Если режим защиты включён и пробуждение не обнаружено, будильник **не срабатывает**, даже если текущее время совпадает с расписанием.
- Уведомление может сработать не более одного раза в календарный день. Без защиты окно проверки — до 10 минут после заданного времени, с защитой — настраиваемое окно 1–5 минут.

## Проверка

1. Дождитесь публикации новой версии на GitHub Pages, полностью перезапустите Lampa.
2. Откройте **Настройки → Будильник**. Убедитесь, что настройки открываются.
3. Откройте карточку любого сериала, нажмите **В будильник** и проверьте, что кнопка изменилась на «Выбран для будильника». В карточке фильма кнопки быть не должно.
4. Вернитесь в **Настройки → Будильник**, проверьте строку выбранного сериала и кнопку **Показать выбранный сериал**. После перезапуска Lampa выбор должен сохраниться.
5. Нажмите **Проверить уведомление**.
6. Выставьте время, сохраните и перезапустите Lampa; проверьте сохранение.
7. Для проверки расписания оставьте экспериментальную защиту выключенной, выставьте время на 2 минуты вперёд, включите будильник и дождитесь тестового уведомления.
8. Для проверки распознавания сна поставьте минимальный простой 15 минут, включите защиту, затем отправьте телевизор в ожидание хотя бы на 15 минут. После пробуждения проверьте пункт **Проверить обнаружение сна**. Внимание: событие может не определиться — это ограничение самого метода.
9. Для диагностики можно вызвать `LampaAlarm.getConfig()`, `LampaAlarm.getWakeState()` и `LampaAlarm.getSelectedSeries()` (если доступна отладка WebView).

**При неудачной проверке настройки TV/ADB не менять без необходимости.** Сообщите, открываются ли настройки, срабатывает ли тестовое уведомление и видит ли детектор пробуждение.

## История версий

- **0.1.3:** диагностический пункт меню; подтверждена загрузка через GitHub Pages.
- **0.2.0:** первый экран настроек и уведомление.

- **0.3.0:** выбор сериала непосредственно из карточки Lampa.

## План

1. Проверка кнопки «В будильник» в настоящих карточках сериалов на Android TV.
2. Сохранение выбранного онлайн-источника/ссылки или торрент-файла при подтверждённом воспроизведении (без хранения секретов).
3. Запуск выбранной серии через совместимые онлайн-плагины и TorrServer.
4. Продолжение с последней серии/позиции.
5. Проверка системной регулировки громкости Android TV и, при необходимости, Android-компаньон.
