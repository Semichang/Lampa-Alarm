# Lampa Alarm

JavaScript-плагин будильника для Lampa (Android TV). Проект находится в разработке.

**Постоянный URL установки:**

`https://semichang.github.io/Lampa-Alarm/alarm.js`

## Версия 0.6.2 — ожидание TorrServer и проверка старта видео

Основная цель обновления: устранить ложную ошибку **«TorrServer не ответил за 15 секунд»** при медленном запуске сериала.

### Как работает запуск сериала через TorrServer

1. **Список файлов**: плагин запрашивает `Lampa.Torserver.files(hash)`. При временной ошибке или отсутствии ответа делает повторные запросы; один неудачный запрос не останавливает запуск.
2. **Предзагрузка** (если в Lampa используется `&preload` и включена настройка «Ждать предварительную загрузку»): использует `Lampa.Reguest` для повторных запросов `preload` / `stat`, как штатная Lampa. Отслеживает `preloaded_bytes / preload_size` до **95%**. Если статистика недоступна, не блокирует запуск навсегда — передаёт ссылку штатному плееру для обычной буферизации.
3. **Передача потока**: после подготовки вызывает `Lampa.Player.play(data)` с новым URL, построенным через `Lampa.Torserver.stream()`.
4. **Проверка фактического старта**: для **внутреннего плеера Lampa** наблюдает `Player:start`, `PlayerVideo:canplay` и `PlayerVideo:timeupdate`. Только положительное продвижение времени видео считается подтверждённым воспроизведением. Событие `canplay` означает лишь готовность плеера к воспроизведению.
5. **Внешний плеер Android**: событие `Player:external` подтверждает **передачу ссылки** внешнему приложению. Плагин не имеет достоверного подтверждения появления первого кадра внутри внешнего плеера и не сообщает «воспроизведение подтверждено».

**Новый максимальный срок ожидания: по умолчанию 180 секунд.** В настройках выбирается 60, 120, 180, 240 или 300 секунд. Этот общий предел охватывает все стадии от запроса файлов до подтверждения начала видео во внутреннем плеере. При внешнем плеере ожидание заканчивается после передачи ссылки с неопределённым статусом фактического воспроизведения.

### Новые настройки в разделе «Подготовка TorrServer»

- **Максимальное ожидание видео** — 1/2/3/4/5 минут, исходно **3 минуты**.
- **Ждать предварительную загрузку** — по умолчанию включено. Работает, если штатный TorrServer сформировал ссылку с `&preload`.
- **Состояние последнего запуска** — этап загрузки, время в секундах, число попыток и доступный процент подготовки буфера.
- **Остановить подготовку** — завершить повторные запросы/ожидание. Уже переданный внешнему приложению поток этим не останавливается.

### Как проверить на телевизоре

1. Дождись публикации новой версии через GitHub Pages и полностью перезапусти Lampa.
2. Зайди в **Настройки → Будильник → Подготовка TorrServer**; оставь ожидание на **3 минуты**, предзагрузку включённой.
3. Нажми **«Запустить сохранённую серию TorrServer»**.
4. Если загрузка долгая, открой **«Состояние последнего запуска»** и посмотри текущий этап: запрос файлов, буферизация, ожидание плеера, воспроизведение подтверждено или передача внешнему плееру.
5. После запуска сравни время подготовки с обычным ручным запуском той же серии.
6. Если снова будет ошибка, запиши точный текст, этап и секунды. Не нужно запускать одну и ту же подготовку повторно, пока первая ещё ожидает ответа.

### Почему загрузка занимает 5–90 секунд

TorrServer получает сегменты файла от участников торрент-раздачи. Скорость зависит от доступности сидеров, сети, кеша на устройстве с TorrServer, количества требуемых начальных данных и формата видео. **Телевизору не нужно скачивать целый сериал**, обычно он проигрывает поток, передаваемый сервером. Если TorrServer находится не на телевизоре, торрент-кеш находится на другом устройстве.

### Остальные функции

- Пункт «Будильник» в настройках, расписание/дни недели; автоматический запуск **по расписанию ещё не включён**.
- Кнопка «В будильник» в карточке сериала.
- Распознавание сезона, серии, онлайн-парсера, балансера/озвучки и позиции при наличии данных.
- История до 60 записей с диагностикой распознавания.
- Ручной повтор TorrServer по сохранённому хэшу и индексу файла, с обновлением потокового URL при каждом запуске.
- Однократный тест запуска серии TorrServer при следующем запуске Lampa или возврате из сна; независим от расписания.
- Ручной повтор онлайн-ссылки только в пределах текущей сессии и короткого времени, потому что ссылки могут истекать.
- Экспериментальная проверка пробуждения Lampa; не позволяет гарантированно определить включение ТВ по расписанию.

**Пока не реализовано:** автоматическое воспроизведение по расписанию, получение новых онлайн-ссылок через любые сторонние парсеры и изменение системной громкости Android TV.

### Безопасность

Плагин не записывает в постоянное хранилище временные URL видео, cookies, токены, HTTP-заголовки или списки файлов. Для TorrServer хранит только хэш торрента, индекс выбранного файла, сезон/серию и статус попытки запуска. Интерфейс статуса не показывает URL.
