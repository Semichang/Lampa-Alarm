# Lampa Alarm

Плагин будильника для **Lampa на Android TV**. Телевизор включается по своему системному расписанию, а Lampa пытается продолжить просмотр выбранного сериала после пробуждения устройства.

**Постоянная ссылка плагина (GitHub Pages):**

`https://semichang.github.io/Lampa-Alarm/alarm.js`

## Версия 0.8.0 — автоматический запуск по расписанию

**В версии 0.8.0 автозапуск по расписанию реализован в тестовом режиме и выключен по умолчанию.** Разовый запуск после включения телевизора через TorrServer уже был успешно проверен пользователем на самом TV; новая связка *расписание → распознавание пробуждения → запуск плеера* пока должна пройти проверку на устройстве.

### Настройка на телевизоре

1. **В Android TV** настрой системное автовключение телевизора. Плагин JavaScript **сам телевизор включить не может**.
2. Открой карточку нужного сериала в Lampa и нажми **«В будильник»**.
3. Запусти нужную серию обычным способом через TorrServer или онлайн-плагин. Плагин запоминает серию, источник, балансер/озвучку, когда они доступны.
4. В **Настройки → Будильник** установи **«Время будильника»**: пультом выбираются часы 00–23, затем минуты 00–59. Выбери дни недели.
5. Включи **«Будильник включён»** и отдельно **«Запускать сериал автоматически»**. Второй переключатель по умолчанию выключен, чтобы новые версии не запускали видео без согласия владельца.
6. Выбери **«Источник серии»**: последний доступный, онлайн или TorrServer. Выбери **«Сохранённая (продолжить)»** либо **«Повторить сохранённую»**.
7. Нажми **«Проверить готовность автозапуска»**. Он покажет время, дни, готовность источника и последний признак пробуждения.
8. Оставь Lampa открытой, выключи ТВ пультом в обычный режим ожидания и дождись его **автоматического** включения по системному таймеру. По умолчанию нужны **не менее 15 минут простоя** и пробуждение в пределах **5 минут после заданного времени**.
9. Если серия не запустилась, открой **«Последняя попытка автозапуска»**, **«Проверить обнаружение сна»** и при необходимости состояния TorrServer / онлайн-теста.

Важно: если один автоматический запуск уже был предпринят сегодня, повторная попытка по расписанию **в этот же день не выполняется**, даже после перезагрузки приложения или изменения времени. Для повторной проверки есть кнопка **«Разрешить повторную проверку сегодня»**: она снимает блокировку сегодняшней попытки, но не запускает видео сразу — нужно новое пробуждение рядом с назначенным временем. Ручные тесты TorrServer и онлайн также остаются доступны.

### Как определяется пробуждение

Приоритет — не прерывать пользователя, который уже смотрит телевизор.

- Автозапуск требует наблюдаемого **длительного простоя Lampa** и возобновления рядом с назначенным временем.
- По умолчанию **«Как распознавать включение» → «Только после наблюдаемого сна Lampa»**: JavaScript фиксирует возврат приложения из скрытого состояния либо большую паузу его таймера. Если просто держать телевизор включённым, время само по себе **не запустит сериал**.
- Для Android TV, который во время сна полностью уничтожает процесс Lampa/WebView, есть альтернативный режим **«После сна или нового запуска Lampa»**. Он использует время последней активности в предыдущей сессии. **Осторожно: этот режим способен сработать при ручном открытии Lampa в заданное время**, потому что JavaScript не знает настоящую причину включения телевизора.
- Пульт/мышь/тач после пробуждения до запуска подавляют автоматический старт.
- Минимальный простой настраивается: 5/15/30/60 минут. Допустимое окно запуска: 1/3/5/10 минут.
- Попытка воспроизведения ограничена **одним разом за календарный день расписания**. Отдельный **«Тест при следующем включении TV»** имеет приоритет над ежедневным запуском.
- Если Lampa не была запущена либо Android не доставил событие пробуждения, JavaScript-будильник может **не сработать**. Для точного определения включения TV по системному расписанию потребуется отдельный Android-компонент или поддержка API конкретного телевизора.

### Источник видео

**TorrServer:** повтор использует сохранённые хэш торрента и номер файла, заново запрашивает список файлов и URL потока, при необходимости ждёт предзагрузку. Максимальное время подготовки видео — от 1 до 5 минут, по умолчанию 3 минуты. Во внутреннем плеере учитывается фактическое движение позиции видео; при внешнем плеере можно подтвердить только передачу ссылки.

**Онлайн:** используется сохранённый маршрут выбранной серии — компонент, балансер, сезон, серия и доступная озвучка. Плагин заново открывает карточку, вызывает установленный онлайн-плагин и выбирает точную совпадающую строку. Этим пользуются AT Anton Online Mod, MODS’s, Lampa Online и предварительные адаптеры для других зарегистрированных компонентов. Если варианты неоднозначны, запуск останавливается для ручного выбора. **Старые URL видеопотоков и токены не сохраняются.**

При варианте **«Последний доступный»** используется последний подходящий источник из истории *выбранного* сериала. Если он не подготовлен к повтору, возможен резервный переход между готовыми сохранёнными онлайн и TorrServer. Это не мониторинг десятков серверов и **не автоматическое перебирание всех онлайн-плагинов при сетевой ошибке**.

Режим **«Следующая непросмотренная» пока не реализован**: для безопасности он блокирует автоматический запуск, чтобы не включить ошибочную серию. Используй сохранённую серию.

### Результаты и диагностика

В настройках доступны:
- **«Проверить готовность автозапуска»** — расписание, источник, признак пробуждения.
- **«Последняя попытка автозапуска»** — дата, способ запуска и статус плеера (если есть).
- **«Состояние последнего запуска»** для TorrServer — этап получения файлов, буферизация, запуск видео.
- **«Состояние онлайн-теста»** и **«Диагностика списка серий»** — открытый онлайн-компонент, распознанные эпизоды, попытка выбора.
- **«Найти онлайн-компоненты»** — какие источники действительно зарегистрированы и открывались в Lampa.

Ручные тесты TorrServer и онлайн-воспроизведения остаются независимыми от ежедневного расписания.

### Пока не реализовано

- Системное включение телевизора **самим** JS-плагином (используй встроенный таймер TV).
- Достоверное различение автовключения по таймеру и ручного открытия Lampa.
- Переход на **следующую** непросмотренную серию с правильным сезоном и озвучкой.
- Плавное повышение **системной громкости Android TV**: сохранённые параметры пока не управляют аппаратной громкостью; может понадобиться Android-компаньон.
- Универсальная гарантия работы со всеми сторонними онлайн-плагинами.
