# Lampa Alarm

Плагин-будильник для Lampa на Android TV. **Тестовый проект**.

**Постоянный адрес установки:**

`https://semichang.github.io/Lampa-Alarm/alarm.js`

## Версия 0.4.0

### Готово и проверяется на телевизоре

- Раздел «Будильник» через штатный `Lampa.SettingsApi`.
- Время запуска (по умолчанию 07:00), включение/отключение, дни недели и тестовые уведомления.
- Выбор сериала непосредственно из его карточки кнопкой **«В будильник»**. Сохраняются название, ID и источник TMDB/CUB.
- Экспериментальная защита от случайного срабатывания: наблюдение длительной паузы Lampa (не равно подтверждённому пробуждению телевизора). По умолчанию **выключена**.
- Настройки будущего продолжения серии, источников онлайн/TorrServer и плавного нарастания громкости.
- **Новое в 0.4.0:** пассивное наблюдение событий плеера `start` и `external` для выбранного сериала. Запоминаются тип источника, распознанные сезон/серия, время просмотра для внутреннего плеера и время последнего запуска.
- Кнопки **«Последняя просмотренная серия»** и **«Очистить историю будильника»**.

### Безопасность и ограничения

- Плагин **не сохраняет URL видео, токены, заголовки авторизации или полный список файлов торрента**. URL онлайн-плагинов часто временные.
- Встроенный проигрыватель может передать сведения о карточке через `data.card`, `data.movie` или метаданные `data.timeline.card`. **Некоторые сторонние онлайн-плагины этих полей не передают.** Тогда запись не появится — это ожидаемое ограничение, а не обязательно неисправность.
- На Android TV видео нередко идёт во внешнем плеере: событие `external` может позволить сохранить название, источник и серию, но **данные о времени воспроизведения обычно недоступны**.
- Номер сезона и серии сохраняется **только если соответствующая информация явно передана Lampa**, без догадок по названию видео.
- **Автоматический запуск видео и изменение громкости пока НЕ реализованы.** Прежде нужно проверить, какие данные отдают установленные источники воспроизведения.
- Тестовый будильник по расписанию пока только показывает уведомление. Телевизор включает его собственный системный таймер.
- Режим определения пробуждения по паузе Lampa экспериментальный: длинная пауза может возникнуть и по другим причинам, а Android иногда полностью уничтожает WebView.

## Тестирование v0.4.0

1. Дождитесь публикации обновления на GitHub Pages и **полностью перезапустите Lampa**.
2. Откройте **Настройки → Будильник**, убедитесь, что раздел загружается, а выбранный сериал на месте.
3. Если сериал ещё не выбран, откройте его карточку и нажмите **«В будильник»**.
4. Обычным способом через онлайн-плагин запустите одну серию, посмотрите 20–30 секунд, выйдите из плеера.
5. Зайдите в **Настройки → Будильник → Последняя просмотренная серия** и проверьте, что отображаются её номер и источник. Если написано, что данных нет, запишите это — потребуется адаптер для используемого онлайн-плагина.
6. Повторите с TorrServer, выбрав файл той же серии. Убедитесь, что распознаётся «TorrServer» (если плеер сообщает `torrent_hash`).
7. После перезапуска Lampa проверьте, что запись сохранилась. Вариант **«Очистить историю будильника»** удаляет только запись нашего плагина.

После каждой проверки сообщите: **онлайн или TorrServer; определились ли сезон/серия; внутренний или внешний плеер**.

## Дальнейшие задачи

1. Подтвердить распознавание реальных серий в установленных онлайн-плагинах и TorrServer.
2. Разработать адаптеры для получения **новой рабочей ссылки** на нужную серию после пробуждения телевизора.
3. Добавить отдельный **ручной тест запуска видео**, и только затем автоматический запуск по расписанию.
4. Проверить повышение системной громкости через Android-компонент, если Lampa не предоставляет такой API.
5. Проверить срабатывание при включении телевизора по системному расписанию.
