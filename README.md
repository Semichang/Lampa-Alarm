# Lampa Alarm

JavaScript-плагин будильника для Lampa (Android TV).

**Постоянная ссылка:** `https://semichang.github.io/Lampa-Alarm/alarm.js`

## Версия 0.5.0 — ручной и одноразовый тест воспроизведения

Реализовано:

- Меню «Будильник», время, дни недели, тестовые уведомления.
- Выбор сериала непосредственно из карточки — кнопка «В будильник».
- Пассивное определение ранее просмотренной серии в онлайн-плеере и TorrServer.
- **Запоминание ID файла и хэша торрента** при просмотре выбранного сериала через TorrServer. Старый URL видеопотока не сохраняется.
- **«Запустить сохранённую серию TorrServer»**: получает у текущего TorrServer новый список файлов по сохранённому хэшу, находит тот же файл по индексу, строит актуальный URL через `Lampa.Torserver.stream()`, запускает `Lampa.Player.play()`.
- **«Повторить недавнюю онлайн-серию»**: пробует повторить видео **только в той же сессии Lampa в течение двух минут**. Ссылка хранится исключительно в оперативной памяти и может перестать действовать раньше.
- **«Тест при следующем включении TV»**: однократный запуск сохранённой серии TorrServer при **новом запуске Lampa** или **возврате из режима ожидания**, без расписания. Флажок снимается *перед* попыткой воспроизведения.
- **«Состояние тестового запуска»**: показывает готовность сохранённой серии и ожидание пробуждения.

### Как проверить однократный запуск после выключения телевизора

1. Дождитесь публикации на GitHub Pages и полностью **перезапустите Lampa**, чтобы загрузилась версия 0.5.0.
2. Перейдите в карточку выбранного для будильника сериала. **Один раз запустите его серию через TorrServer**, дождитесь начала воспроизведения и выйдите. Это обязательно: версия 0.4.0 ещё не сохраняла хэш и индекс для повтора.
3. Откройте «Настройки → Будильник → Состояние тестового запуска»: должен появиться текст, что сохранённая серия TorrServer готова.
4. Сначала выполните **«Запустить сохранённую серию TorrServer»** и проверьте, что запускается нужная серия без выбора файла.
5. Если ручной запуск прошёл успешно, включите переключатель **«Тест при следующем включении TV»**. Должно появиться уведомление «Тест подготовлен».
6. Оставьте Lampa открытой, выключите телевизор обычной кнопкой питания, **подождите хотя бы 30 секунд**, включите телевизор. Если Lampa восстановилась, плагин должен попытаться запустить сохранённую серию без нажатия кнопок.
7. При срабатывании переключатель автоматически станет выключенным. Если не сработало, проверьте статус и сообщите, каким способом просыпается телевизор (возобновляет приложение или запускает Lampa с нуля).

### Ограничения и безопасность

- Автоматический запуск по ежедневному расписанию **ещё не включён**. Штатное расписание пока проверяется уведомлением. Одноразовый тест независим от времени 07:00.
- Плагин **не включает телевизор самостоятельно**; включение обеспечивает таймер Android TV или пользователь.
- Текущий тест после полного выключения рассчитан **на TorrServer**, потому что он позволяет получить новую ссылку на существующий торрент. Универсального стабильного API повторного воспроизведения для всех сторонних онлайн-плагинов нет. Временно разрешён только ручной онлайн-повтор в той же сессии.
- **Проверка пробуждения эвристическая**: WebView Android может быть приостановлен без события `visibilitychange`. Для определения возврата также используется пауза JS-таймера. После сна короче 30 секунд повтор может не сработать, а возобновление Lampa из другого приложения может выглядеть как пробуждение телевизора.
- Состояние одноразового теста сохраняется через `Lampa.Storage`; настройка снимается **перед попыткой воспроизведения**, чтобы избежать циклов при сбоях.
- Для воспроизведения TorServer должен быть доступен с телевизора. В случае ошибки запуска плагин сообщает о ней и не возобновляет попытки бесконечно.
- В Lampa.Storage сохраняется лишь идентичность торрента/файла (хэш, индекс, сезон, серия). Потоковые URL, токены, cookies, HTTP-заголовки и плейлисты **не сохраняются**.
- Регулировка системной громкости пока не реализована.
- Экспериментальная защита обычного расписания «Только после пробуждения» по умолчанию выключена и не влияет на одноразовый тест.

## История

- **0.1.3** — рабочий диагностический пункт меню через GitHub Pages.
- **0.2.0–0.2.2** — параметры расписания, настройки и определение возможного пробуждения.
- **0.3.0** — выбор сериала из карточки.
- **0.4.0** — отслеживание просмотров через онлайн/TorrServer.
- **0.5.0** — повтор файла TorrServer по актуальной ссылке и одноразовый тест при следующем запуске/пробуждении Lampa.

## Следующие шаги

1. Реальный тест запуска серии из состояния ожидания Android TV.
2. Автоматический запуск по расписанию с надёжной защитой от включения при обычном просмотре.
3. Адаптеры для конкретных онлайн-плагинов и выбор следующей серии.
4. Плавное увеличение системной громкости Android TV до прежнего уровня или установленного предела.
