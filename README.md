# Lampa Alarm

Будильник-плагин для Lampa на Android TV. Установка один раз через GitHub Pages:

`https://semichang.github.io/Lampa-Alarm/alarm.js`

## Версия 0.2.0 (тестовая)

- Раздел «Будильник» в настройках Lampa.
- Время срабатывания в формате ЧЧ:ММ (по умолчанию 07:00).
- Включение/отключение будильника, выбор дней недели.
- Проверка времени каждые 15 секунд, при возврате фокуса и после возобновления Lampa.
- Окно запуска до 10 минут после установленного времени; одно срабатывание в календарный день.
- Тестовое уведомление и просмотр сохранённых настроек.
- Параметры для будущих режимов онлайн/TorrServer и постепенного повышения громкости.

### Важно

В версии 0.2.0 будильник **только показывает уведомление**, он ещё **не запускает видеосерии и не изменяет системную громкость**. Настройки этих функций сейчас сохраняются, но ничего не выполняют. Телевизор должен сам включаться по штатному расписанию; JavaScript-плагин не может вывести из глубокого сна выключенное устройство.

Раздел настроек использует `Lampa.SettingsApi`. Параметры сохраняются в `Lampa.Storage` с префиксом `la_`. По умолчанию будильник **выключен**, чтобы случайно не срабатывать при установке.

### Проверка на телевизоре

1. Полностью закрой и снова открой Lampa после обновления файла на GitHub Pages (обновление может кешироваться).
2. Перейди в «Настройки → Будильник».
3. Измени время, включи нужные дни недели, включи будильник.
4. Нажми «Проверить уведомление» и «Показать текущие настройки».
5. Полностью закрой и снова запусти Lampa; проверь, что введённое время и другие параметры сохранились.
6. Для теста расписания установи время на 1–2 минуты позже текущего и дождись уведомления.

Если настройки не отображаются, используйте ADB для диагностики. Файл `alarm.js` — единственная точка подключения; URL менять при обновлениях не нужно.

## План

1. Выбор сериала из карточки Lampa.
2. Адаптеры для онлайн-источников и TorrServer.
3. Продолжение с нужной серии/позиции.
4. Регулировка системной громкости Android TV (после проверки доступного API / отдельного Android-компонента).
5. Тестирование после выхода телевизора из сна.
