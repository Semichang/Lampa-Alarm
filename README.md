# Lampa Alarm

JavaScript-плагин для Lampa на Android TV. Проект в разработке: управление включением телевизора остаётся за системным таймером Android TV.

**Постоянный адрес установки:**

`https://semichang.github.io/Lampa-Alarm/alarm.js`

## Версия 0.6.1 — запоминание серий из разных онлайн-плагинов

### Что уже работает

- Настройки времени и дней недели будильника; пока только уведомление по расписанию.
- Кнопка **«В будильник»** в карточке сериала.
- Одноразовый тест запуска серии после следующего запуска/возврата Lampa из сна — только TorrServer, не расписание.
- Ручной повтор серии TorrServer по **хэшу торрента и индексу файла** (URL запрашивается заново).
- Временный ручной повтор онлайн-серии в той же сессии Lampa, пока ссылка свежая.
- **Сбор метаданных просмотра** из `Player:start`, `Player:external`, `Player:create`, активного онлайн-экрана и (при наличии) выделенной строки серии.
- Распознавание обозначений **S02E03, 02x03, S03 / 5, «Сезон 2 / Серия 3», «2 сезон 8 серия», «3 серия», «Episode 03»** и т.п.
- Поддержка типовых данных **Lampa Online** и **AT Anton Online Mod**: название плагина, выбранный балансер (через поля `online_balanser` или `online_mod_balanser` и историю для конкретного сериала), озвучка, качество при наличии.
- **История до 60 записей** с названием сериала, сезоном/серией, источником, плеером и временем воспроизведения.
- **Диагностика распознавания**: объясняет, удалось ли сопоставить видео с сериалом и определить номер серии.
- Защита от случайной подстановки серии из ранее открытого онлайн-плагина, если уже перешли к другой карточке или в главное меню.

### Важно об ограничениях

**Видеоссылки, токены, cookies, заголовки авторизации и плейлисты в постоянное хранилище не записываются.** Для TorrServer сохраняется только идентификатор торрента и номер файла; для онлайн — доступная метаинформация о просмотре.

У сторонних парсеров нет единого обязательного контракта. Иногда они передают только название сериала без номера эпизода. Если номер не удаётся получить ни из данных плеера, ни из активного списка, показывается **«серия не определена»**, а не придумывается номер. Такие случаи можно исправить отдельным адаптером после диагностики конкретного плагина.

Системная громкость Android TV пока **не регулируется**, а ежедневный будильник **не запускает видео автоматически**. Экспериментальная проверка пробуждения Lampa не подтверждает, что телевизор включился по расписанию.

## Проверка на телевизоре

1. Дождись публикации GitHub Pages и полностью перезапусти Lampa.
2. Открой **Настройки → Будильник**, убедись, что выбранный сериал сохранился.
3. Запусти сериал через **AT Anton Online Mod**, выбери балансер и серию, посмотри 15–30 секунд.
4. Открой **«Последняя просмотренная серия»**, затем **«Источник и озвучка последней серии»**.
5. Открой **«История просмотров будильника»**. Проверь, что там сохранены сериал, сезон, серия и источник.
6. Повтори с другим установленным онлайн-плагином и с TorrServer.
7. Если номер серии или источник не определились, нажми **«Диагностика распознавания серии»** и сообщи текст сообщения вместе с названием онлайн-плагина.

### Проверка одноразового теста включения TV

Сначала запусти выбранную серию через TorrServer, затем проверь кнопку **«Проверить сохранение файла TorrServer»**. При успешном сохранении попробуй **«Запустить сохранённую серию TorrServer»**. Только после успешного ручного запуска включи **«Тест при следующем включении TV»**, оставь Lampa открытой, выключи телевизор и включи обратно через 30 секунд. Тест выключится после первой попытки запуска.
