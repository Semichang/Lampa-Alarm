# Lampa Alarm

JavaScript-плагин будильника для Lampa на Android TV. В разработке.

**Постоянный URL для установки и обновлений:**

`https://semichang.github.io/Lampa-Alarm/alarm.js`

## Версия 0.7.0 — повторный запуск онлайн-серии (ручной тест)

Добавлен новый раздел в **Настройки → Будильник → Повтор онлайн-серии — тест**.

- **Сохранённый онлайн-маршрут** показывает серию, плагин, балансер и номер эпизода. Источник берётся из последней *онлайн*-записи истории **для выбранного сериала**; если позже смотрели TorrServer, эта запись остаётся доступной.
- **Открыть сохранённый онлайн-источник** заново открывает карточку сериала, а затем её кнопку соответствующего плагина. Ничего автоматически не воспроизводит; серию выбирает пользователь.
- **Тест выбора онлайн-серии** заново открывает карточку, выбранный источник, ждёт список эпизодов и пробует нажать на **точно совпадающий сезон и серию**. Если список однозначен, обработчик самого онлайн-плагина получает `hover:enter` и **сам заново извлекает актуальный поток**.
- **Состояние онлайн-теста** показывает этап проверки (открытие карточки, источник, список, видеоплеер, результат) и время ожидания. Ожидание ограничено 120 секундами.
- **Отменить онлайн-тест** останавливает автоматический поиск/выбор, но не закрывает уже открытый вручную экран.

### Какие плагины

Проверены по исходникам: **AT Anton Online Mod** (`online_mod`), штатный **Lampa Online** (`online`), а также схожий **Online Prestige** (`online_prestige`). Они создают штатные экраны Lampa, в которых выбор серии приводит к получению свежей ссылки.

Для других установленных компонентов с онлайн-форматом предусмотрена осторожная попытка открыть **только зарегистрированный** в Lampa компонент. Если он использует другое оформление списка, автоматический выбор не происходит. Наличие плагина на телевизоре ещё не означает, что его API полностью совместим.

### Ограничения безопасности и точности

- Если в сохранённой записи нет номера сезона/серии, плагин открывает онлайн-источник для ручного выбора, но **не угадывает номер**.
- При нескольких совпадающих эпизодах и неоднозначной озвучке, либо если обнаружена другая озвучка, автоматический тест останавливается и оставляет список открытым.
- Если выбран другой сериал, показана чужая карточка или пользователь покинул онлайн-экран, тест прекращает работу.
- **Никакие URL потоков, cookies, авторизационные токены или плейлисты не сохраняются в постоянное хранилище.** В истории хранятся название сериала, ID, онлайн-компонент, балансер, озвучка, сезон и серия, когда эти поля доступны.
- Тест активируется **только вручную** в настройках; автоматический запуск онлайн-видео при включении TV и запуске по расписанию пока не реализован.
- Во внутреннем плеере начало воспроизведения подтверждается движением времени видео. Для внешнего Android-плеера доступно подтверждение передачи ссылки, но не первого кадра.

### Как проверять на телевизоре

1. Дождись публикации GitHub Pages и полностью перезапусти Lampa.
2. Выбери сериал кнопкой **«В будильник»** в карточке, открой через любой из установленных онлайн-плагинов нужную серию и посмотри её хотя бы 15–30 секунд.
3. В разделе **«Последняя просмотренная серия»** проверь, что записались сезон, серия, плагин и балансер. Если перед этим смотрелся TorrServer, можно посмотреть онлайн-запись в **«Истории просмотров будильника»**.
4. Выбери **«Сохранённый онлайн-маршрут»**, чтобы убедиться, что запись доступна.
5. Нажми **«Открыть сохранённый онлайн-источник»**. Если открылась нужная карточка и список серий, вернись в настройки.
6. Нажми **«Тест выбора онлайн-серии»**. Плагин попробует получить свежую ссылку через прежний онлайн-источник.
7. Если воспроизведение не стартовало, открой **«Состояние онлайн-теста»**. Сообщи точный текст результата, название плагина и название используемого балансера.

**Внимание:** этот способ ещё не подтверждён на твоём телевизоре. Не включай будильник для автозапуска видео, пока не проверим тестовые действия.

## TorrServer — версия 0.6.2

Часть TorrServer не менялась при разработке 0.7.0. По сообщению пользователя ручной и одноразовый тестовый запуск на телевизоре работают.

Текущий запуск TorrServer использует повторные запросы списка файлов, предзагрузку при доступном `&preload`, максимальный срок ожидания 60–300 секунд (по умолчанию 180) и проверку событий видеоплеера. Для внешнего плеера подтверждается только передача ссылки.

## Остальные возможности

- Расписание и дни недели; пока **уведомления**, не автовоспроизведение.
- Выбор сериала в карточке, история до 60 серий и источников.
- Экспериментальное наблюдение пробуждения Lampa. Не позволяет точно установить, что TV включился по встроенному таймеру.
- Отсутствует регулировка системной громкости Android TV; предстоит проверить Android API/компаньон.
